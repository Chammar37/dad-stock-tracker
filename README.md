# Stock Tracker App

A personal stock tracking application built with Streamlit that helps you manage your stock portfolio across multiple accounts (TFSA, RRSP, Personal, etc.).

## Features

- **Consolidated Record**: View all holdings across all accounts with automatic calculations
- **Trade Entry**: Record buy/sell/transfer trades with automatic cost basis updates
- **Pre-populate Database**: Add existing holdings to get started quickly
- **Trade History**: View all past trades with filtering capabilities

## Installation

1. Clone or download this repository
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Run the application:
   ```bash
   streamlit run app.py
   ```

2. Open your browser to the URL shown in the terminal (usually http://localhost:8501)

## Getting Started

1. **Pre-populate Database**: If you have existing holdings, use this page to add them
2. **Trade Entry**: Record new trades as they happen
3. **Consolidated Record**: View your current portfolio status
4. **Trade History**: Review all your past trades

## Data Storage

By default, the app stores data in CSV files in the `data/` directory:
- `consolidated.csv`: Current holdings and their cost basis
- `trades.csv`: Complete trade history

The app can also use Supabase Postgres for persistent storage. The CSV backend remains
the fallback when no storage backend is configured.

### Supabase Storage

1. Create the Supabase tables with this schema:

   ```sql
   create table if not exists holdings (
     id bigint generated by default as identity primary key,
     account text not null,
     stock_name text not null,
     stock_symbol text not null,
     quantity integer not null default 0,
     average_price_per_share numeric(18, 6) not null default 0,
     capital_gain_loss numeric(18, 2) not null default 0,
     date_of_acquisition date,
     created_at timestamptz not null default now(),
     updated_at timestamptz not null default now(),
     unique (account, stock_symbol)
   );

   create table if not exists trades (
     id bigint generated by default as identity primary key,
     account text not null,
     stock_name text not null,
     stock_symbol text not null,
     date_of_trade date not null,
     trade_type text not null check (trade_type in ('B', 'S', 'T')),
     shares_traded integer not null check (shares_traded > 0),
     price_per_share numeric(18, 6) not null,
     commission numeric(18, 2) not null default 0,
     cost numeric(18, 2),
     gross_proceeds numeric(18, 2),
     net_proceeds numeric(18, 2),
     average_cost_at_sale numeric(18, 6),
     capital_gain_loss numeric(18, 2),
     created_at timestamptz not null default now()
   );
   ```

2. For local development, copy `.streamlit/secrets.example.toml` to
   `.streamlit/secrets.toml`, set `[storage].backend = "supabase"`, and replace the
   example URL with the Supabase Postgres connection string. Do not commit
   `.streamlit/secrets.toml`. An existing `.env` file is also supported with
   `STOCK_TRACKER_STORAGE_BACKEND=supabase`, `SUPABASE_DATABASE_URL`, and optionally
   `STOCK_TRACKER_APP_PASSWORD`.

3. For Streamlit Cloud, add the same TOML values in the app dashboard under
   Settings -> Secrets. Keep the database URL and app password out of browser-side
   code and logs. If `[auth].app_password` is configured, the app requires that
   password before loading portfolio data.

4. To force a backend locally without editing secrets, set:

   ```bash
   export STOCK_TRACKER_STORAGE_BACKEND=supabase
   ```

5. To copy existing CSV data into Supabase once the tables and secrets are ready:

   ```bash
   python scripts/migrate_csv_to_supabase.py
   ```

Trade entry uses a single transaction for the trade history insert and holdings
update when the SQL backend is selected. Invalid sells are validated before any
trade history row is written.

## Calculations

The app automatically calculates:
- **Average cost per share** when buying stocks
- **Capital gains/losses** when selling stocks
- **Portfolio value** and performance metrics

## Account Types

The app supports multiple account types such as:
- TFSA (Tax-Free Savings Account)
- RRSP (Registered Retirement Savings Plan)
- Personal accounts
- Any other account type you specify
